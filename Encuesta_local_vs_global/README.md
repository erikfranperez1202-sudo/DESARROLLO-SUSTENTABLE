# Nombre del proyecto
ENCUESTA LOCAL VS GLOBAL

## Descripción
el objetivo de este codigo expone una encuesta la cual ayuda a saber el tipo de compras que hacen y donde las hacen.

## Objetivos de aprendizaje
expone una automatizacion en make y consiste mediante una encuesta hacer preguntas y guarda las respuestas en una tabla de google sheets y las clasifica mediante las respuestas.

## Material utilizado
Enumera todos los componentes usados:
- make
- google sheets
- telefono
- laptop
- github
